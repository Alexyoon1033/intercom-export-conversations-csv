Direct-to-disk streaming and IndexedDB checkpoints

Concatenating 50,000 HTML conversations into a single JavaScript string or Blob crashes browser tabs at the 500 MB UTF-16 string limit. ChatVault opens a native FileSystemWritableFileStream handle and flushes batches to disk every 50 conversations.

  • IndexedDB cursor persistence. Every 50 conversations, ChatVault records the active starting_after cursor and completed conversation IDs. Interrupted runs resume from the exact ticket.
  • Fault-tolerant 404/403 skipping. Deleted or restricted tickets mid-batch are logged in skipped_errors without halting a multi-hour export.

Search API filtering, Deep Export, and 3 output schemas

Filter exact slices using POST /conversations/search (Start Date, End Date, Tag name/ID, State) instead of dumping 80,000 irrelevant tickets, and probe US, EU, and AU gateways automatically.

  • Deep Export enrichment & local ZIP bundle. Optionally merge GET /contacts/{id} companies, custom attributes, and SLA statistics, plus package transcripts, attachment manifests, and skipped_errors.json locally.
  • Clean Excel CSV, NDJSON, and Obsidian Markdown. UTF-8 BOM (\uFEFF), RFC 4180 quote escaping, HTML tag stripping, 32,000-char Excel cell guard, and Summary or Detailed row granularity.
